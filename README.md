# SpyNote v6.5 (RedMoon Edition)

In this repository, I have cleaned the SpyNote v6.4 utility of the built-in backdoors, viruses, and nested RATs (RAT-within-a-RAT) found in other versions. I also fixed compilation issues present in existing open-source repositories for this tool and made a few adjustments. I added some personal features, such as screen sharing and notifications about connected devices via Discord or Telegram bots. Additionally, I created a custom GUI and allowed for background customization within the utility window via the `assets` folder, resulting in a much more pleasant interface. Regarding functionality, I also planned to update manifests to evade Play Protect detection, create a dropper, implement a package generator, and add APK masking capabilities.
